# Historical academic source archive

This directory is not an application backend. The previous Python API, fixed guided flow, student Markdown records, prompt files, and generated syllabus summaries were removed for the rebuild.

School_Master_Wiki/01_Raw_Sources is an untouched reference archive of older CBSE and NCERT-related material. Preserve it exactly as found. It is not verified for the new grades 6–12 product and must not be imported automatically. Check grade, board, academic year, source rights, and extracted text before using any file.

School_Master_Wiki/log.md records the earlier wiki work and is retained as provenance. New application data will live in PostgreSQL and private file storage as described in the root ARCHITECTURE.md.
