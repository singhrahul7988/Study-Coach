# Curation layout review

The previous screen placed the main status below the checklist, used a large decorative circle, and put the class/pace badge beside the steps. This left excess empty space on desktop and squeezed the labels on phones.

The updated screen leads with the purpose and current step, keeps student context inside one compact panel, and uses a progress bar with five readable preparation steps. The active step is repeated by the progress bar so it remains visible on short phones. Status and fallback copy continue to follow real profile, Library, and Coach work.
