# Screen review: blue and white palette

Captured at 1440 × 900 desktop and 390 × 844 mobile. Every row has a [before](./icon-palette-before/) and [after](./icon-palette-after-1/) capture in both sizes. Capture filenames are the row prefix followed by `-desktop.png` or `-mobile.png`.

| Screen / capture prefix | Review and outcome |
| --- | --- |
| Landing (`01-landing`) | Blue and white hero, black headline, grey support copy, and blue action were already balanced. Kept the composition. |
| Setup (`02-setup`) | Input and selection spacing stayed consistent. Made the back icon blue. |
| Curation (`03-curating`) | Blue and white waveform and restrained motion already matched the palette. Kept it. |
| Coach start (`04-coach-start`) | Chat and plan panel use white cards, blue action, black titles, and grey details. Gave the coach icon violet and plan time icon amber for distinction. |
| Profile menu (`04-profile-menu`) | Menu alignment and placement were sound. Profile, settings, and sign out now have distinct icon colors on neutral icon backgrounds. |
| Settings (`04-profile-settings`) | Profile and API fields were aligned and legible. Gemini and Deepgram service icons now have distinct violet and teal cues on grey containers. |
| My profile (`04-my-profile`) | Achievement cards retained their neutral surfaces. Earned achievements get a teal icon; locked achievements stay grey to communicate their state. |
| Coach conversation (`04-coach`) | Answer cards, task selection, and study room action retained their blue and white hierarchy. Planning, source, and timing icons now differ by color. |
| Today (`05-today`) | Kept the compact layout and blue action. Pace and material icons now use teal and amber while card surfaces stay white. |
| Study room (`06-study-room`) | Chat, timer, and task area retained the blue and white hierarchy. Quiz, self-check, and hint icons now differ by color. |
| Library (`07-library`) | File cards remain neutral. File-type and action icons now have distinct colors so document roles are easier to scan. |
| Library document (`08-library-document`) | The long document view keeps its vertical reading flow. Neutralized file icon backgrounds; colored document actions only. |
| Document study (`09-study-document`) | Replaced a stray green document border with grey and added teal, violet, and amber icon cues for source, saved question, and time. |
| Progress (`10-progress`) | Summary icons now distinguish evidence, tasks, and time; a stray colored divider is neutral. |
| Empty Library (`11-library-empty`) | The empty-state card remains simple; its icon now provides a violet cue. |
| Empty Study (`12-study-empty`) | The prompt is near the top, with a clear blue Coach action. The Study navigation icon is teal. |
| Empty Progress (`13-progress-empty`) | The card sits near its heading and the Coach action is blue. The empty-state icon is violet. |

The after captures have no horizontal page overflow. Desktop Landing, Setup, Curation, Coach, Today, Study room, and the empty states fit within 900 px; longer profile, settings, and document pages scroll for their content.
