# Settings cleanup

The original Settings screen repeated navigation to My profile and used a second card to explain implementation details. The updated screen keeps key entry in a single card and uses a short note about when saved keys are used.

- [Desktop before](desktop-before.png) / [desktop after](desktop-after.png)
- [Mobile before](mobile-before.png) / [mobile after](mobile-after.png)

The revised desktop page fits a 1440 x 900 viewport. At 390 px wide, the page has no horizontal overflow and no link back to My profile in its main content. Gemini and Deepgram key entry and save behavior remain available.
